# Yemen AI v7.3 — Seed Knowledge Base
This release adds a structured initial knowledge package separated from application code.

## Knowledge domains
System identity, founder/project context, Yemen, AI, computer science, programming, architecture, science, education, business, security, data, Yemen AI project memory and developer reference.

## Design decisions
- Seed knowledge is external to core application code.
- Files are Markdown for portability and version control.
- Founder context is limited to project/professional context.
- Current or sensitive facts should be refreshed from verified sources.
- The existing Training Engine can ingest this package using its normal workflow.

## Recommended next step
Add a bulk seed-import action to automatically ingest and index the package on a fresh installation, with duplicate detection and import audit logs.
