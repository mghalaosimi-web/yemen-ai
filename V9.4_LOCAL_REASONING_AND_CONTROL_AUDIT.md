# Yemen AI v9.4 — Local Reasoning & Control Audit

## Scope
Offline-only upgrade built on v9.3. No cloud APIs or external model dependency was added.

## Added
- Evidence trace for each retrieval-backed answer: source, page, score, matched concepts and excerpt.
- Conservative conflict detector for contradictory evidence markers.
- Confidence calibration using base confidence, retrieval strength, evidence coverage and conflict penalty.
- Related concept lookup through the existing local knowledge graph.
- Operational audit endpoint and index reload/validation control.
- Regression tests for evidence tracing, conflict signaling and confidence calibration.

## Validation
- Python compilation: passed.
- Full test suite: 69 passed.

## Important boundary
This remains a deterministic local knowledge/retrieval system, not a trained large language model. The new controls make its reasoning path more inspectable and safer rather than pretending to provide hidden chain-of-thought.
