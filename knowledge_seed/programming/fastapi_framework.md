# Overview

## Arabic Explanation
إطار عمل فاست إيه بي آي (FastAPI) هو إطار حديث عالي الأداء لبناء واجهات برمجة التطبيقات (APIs) بلغة بايثون اعتمادًا على التلميحات النوعية Standard Python type hints.

## English Explanation
FastAPI is a modern, high-performance web framework for building APIs with Python based on standard Python type hints, featuring automatic OpenAPI documentation and Pydantic validation.

## Key Concepts
- Async / Await Execution
- Pydantic Data Models
- Automatic OpenAPI Docs
- Dependency Injection

## Definitions
- FastAPI: Python API framework.
- Uvicorn: Lightning-fast ASGI server implementation.

## Examples
- `from fastapi import FastAPI; app = FastAPI()`

## Relationships
- FastAPI uses Starlette & Pydantic
- Yemen AI uses FastAPI for HTTP endpoints

- Endpoint -> نقطة النهاية البرمجية
