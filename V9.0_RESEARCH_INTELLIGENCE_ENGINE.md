# Yemen AI v9.0 — Research Intelligence Engine

## Added capabilities
- Whole-document evidence-grounded summary with page references.
- Key-point extraction from document evidence.
- Study-plan generation distributed across actual document pages.
- Grounded quiz generation with answer evidence and page numbers.
- Cross-document search across up to 10 owned documents.
- Ownership checks on every new research operation.
- No external facts are added by the research workspace.

## API
- GET `/api/chat/documents/{id}/summary`
- GET `/api/chat/documents/{id}/key-points`
- POST `/api/chat/documents/{id}/study-plan`
- GET `/api/chat/documents/{id}/quiz`
- GET `/api/chat/documents/search?q=...&document_ids=id1,id2`
