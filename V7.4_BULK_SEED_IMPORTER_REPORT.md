# Yemen AI v7.4 — Bulk Seed Importer

## Added
- Automatic first-start import of `knowledge_seed/` into the RAG vector store.
- SHA-256 fingerprint state to prevent duplicate imports.
- Manual API controls:
  - `GET /api/seed/status`
  - `POST /api/seed/import`
  - `POST /api/seed/import?force=true`
- Import audit activity.

## Behavior
On startup Yemen AI checks the seed library. If its fingerprint has not been imported, all supported files are chunked and indexed. Later startups skip unchanged seed data.
