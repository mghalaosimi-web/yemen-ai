# Yemen AI v8.0 — Integrated Intelligence Platform

## Included
- Unified role-based access and protected portals
- Seed knowledge import with fingerprint deduplication
- File ingestion and RAG retrieval
- Session memory and answer feedback
- Training and model-control modules retained from previous releases
- Knowledge Graph layer: entity extraction, graph nodes, co-occurrence edges, graph search and graph context in intelligence responses
- Responsive RTL/LTR interface, theme controls, confirmation dialogs and protected destructive actions
- Launcher now checks and installs missing Python runtime dependencies automatically

## Verification
Run `py -m pytest -q` after installation.

## Security note
Demo credentials are for local development only. Change passwords and `YEMEN_AI_SECRET_KEY` before public deployment.
