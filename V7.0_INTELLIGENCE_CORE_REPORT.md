# Yemen AI v7.0 — Intelligence Core

## Scope completed
- Unified AI provider abstraction with local fallback, Ollama, and OpenAI-compatible APIs.
- Provider status reporting without exposing secret API keys.
- RAG retrieval relevance threshold to reduce unrelated context injection.
- Source relevance metadata included in the prompt pipeline.
- Explicit operational/degraded status for AI responses.
- Protected intelligence health, chat, and ingestion endpoints.
- Added automated v7.0 intelligence contract tests.

## Safety and deployment notes
- Secrets remain environment variables and are not returned by status endpoints.
- Uploaded-file ingestion continues to restrict paths to the upload directory.
- Echo mode is intentionally a development fallback, not a production language model.
- For production: use PostgreSQL, a dedicated vector database, background ingestion workers, rate limiting, HTTPS, and monitoring.
