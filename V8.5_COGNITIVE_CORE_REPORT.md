# Yemen AI v8.5 — Cognitive Core

## What changed
- Arabic-first normalization with dialect aliases and safer word boundaries.
- Intent detection expanded to definition, explanation, why, how, steps, comparison, continuation and more.
- Query expansion with synonyms and lightweight Arabic stemming.
- Multi-stage pipeline: understand → retrieve → rerank → synthesize → self-check → abstain when evidence is weak.
- Sentence-level evidence selection and near-duplicate suppression.
- Structured answer styles instead of raw knowledge dumps.
- Safe arithmetic evaluator with AST restrictions.
- Confidence metadata and pipeline telemetry for internal diagnostics.
- User feedback endpoint; explicit low-rated corrections can be stored as local knowledge.
- Offline-first architecture retained: no external AI API is required.

## Important limitation
This is a stronger local reasoning/retrieval system, not a replacement for a frontier-scale neural language model. Its quality depends on the local knowledge base and the rules/models available offline.
