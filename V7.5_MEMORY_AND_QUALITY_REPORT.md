# Yemen AI v7.5 — Memory & Quality Layer

## Implemented
- Session-scoped conversation memory.
- Persistent SQLite memory records separated by session.
- Explicit memory inspection API.
- User-controlled memory deletion endpoint.
- Answer feedback collection (1–5 rating + notes).
- RAG + conversation context composition.
- No automatic hidden personal profiling; saved context is traceable to the session and removable.

## Endpoints
- `POST /api/intelligence/chat`
- `GET /api/intelligence/memory/{session_id}`
- `DELETE /api/intelligence/memory/{session_id}`
- `POST /api/intelligence/feedback`

## Quality principles
- Relevance: local RAG knowledge remains primary for factual retrieval.
- Transparency: context/memory counts are returned by chat.
- Control: memory can be inspected and deleted.
- Separation: session memory is not global knowledge.
