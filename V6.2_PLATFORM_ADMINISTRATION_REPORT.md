# Yemen AI v6.2 Platform Administration

Implemented from v6.1 without resetting existing data.

## Added
- Admin-only user management API and interface
- Create user with validation and duplicate protection
- Change roles with self-admin lockout protection
- Delete users with self-delete protection and confirmation UI
- Persistent settings storage
- System event logging primitives
- Developer workspace expanded into operational administration space

## Data compatibility
Database migrations use CREATE TABLE IF NOT EXISTS and preserve existing records.
