# Yemen AI v9.3 — Local Intelligence Upgrade & Audit

## What changed
- Unified enrichment after ingestion: concepts, lightweight relations, and multiple QA cards.
- Arabic-aware query expansion now runs inside hybrid retrieval, not only the chat reasoning layer.
- Training artifacts are explicitly tagged (`concept_index`, `qa_card`) and remain locally persisted.
- Added regression tests for concept extraction, relation extraction, and richer QA generation.

## Validation
- Full pytest suite executed successfully.
- Python bytecode compilation executed successfully.
- No external API or cloud dependency was introduced.

## Honest boundary
This remains a local retrieval-and-reasoning architecture, not a locally fine-tuned foundation model. The upgrade improves ingestion, recall, paraphrase handling and inspectability without pretending to be ChatGPT-scale training.
